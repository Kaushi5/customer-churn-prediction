# 📊 Customer Churn Prediction  

Welcome to the **Customer Churn Prediction** project! 🚀  
This repository is dedicated to predicting customer churn using data-driven machine learning techniques. Let's dive into the data and gain actionable insights to improve customer retention! 💡  

## 🌟 Project Overview  

Customer churn is a major challenge for businesses. This project aims to build a robust machine learning model to predict churn, helping businesses retain valuable customers. 💼  

### ✨ Highlights:  
- 🔍 **Data Analysis**: Explore trends and patterns in customer behavior.  
- 🛠️ **Preprocessing**: Clean and prepare data for better model performance.  
- 🤖 **Machine Learning**: Train and evaluate models to predict churn effectively.  
- 📈 **Visualization**: Beautiful and intuitive insights from the data.

## 🚀 Getting Started  

### Prerequisites  
Make sure you have Python 3.8+ installed.  

### Steps to Run:  
1. Clone the repository:  
   ```bash  
   git clone https://github.com/Kaushi5/customer-churn-prediction.git  
   cd customer-churn-prediction  
   ```  
2. Install dependencies:  
   ```bash  
   pip install -r requirements.txt  
   ```  
3. Open the Jupyter Notebook:  
   ```bash  
   jupyter notebook Customer\ churn\ prediction.ipynb  
   ```

## 🧪 Conclusion 

This project successfully developed and evaluated multiple machine learning models to predict customer churn. Among them, the XGBoost classifier, fine-tuned through hyperparameter optimization, emerged as the top performer, achieving an outstanding ROC-AUC score. Key factors influencing customer churn were identified, including Total Spend, Support Calls, and Payment Delay, providing actionable insights for businesses.

By accurately predicting customer churn, organizations can proactively engage with at-risk customers through tailored retention strategies, reducing churn rates while enhancing customer lifetime value and overall business profitability.
